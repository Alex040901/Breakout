# 🏓 Breakout / Arkanoid - Pygame

Proyecto de la Fase 1 (Fundamentos en Python) enfocado en simulación de física continua en 2D, vectores de velocidad, ángulos de rebote dinámicos y destrucción de bloques.

## 🛠️ Estado del Proyecto & Checklist

- [ ] Configuración de la ventana y Game Loop.
- [ ] Control de la paleta (Paddle) con límites de pantalla.
- [ ] Física de la pelota (vectores $VX, VY$).
- [ ] Rebote en paredes (izquierda, derecha, arriba).
- [ ] Rebote en paleta con ángulo dinámico.
- [ ] Generación de matriz de bloques (*Bricks Grid*).
- [ ] Destrucción de bloques al detectar colisión.
- [ ] Sistema de vidas y caída de pelota (Game Over / Victoria).
- [ ] Marcador de puntos y High Score.
